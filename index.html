Learning Rules

For each topic: Learn → Practice → Questions → Debug → Build → Test → Break It → Fix It → Project → Assessment → Mastery Gate → Next Topic.

Questions should be topic-specific and progressive. Answers are attempted first. Repeated mistakes trigger revision instead of automatic advancement. Every serious feature should include “What can break?” and tests.
